# ros2-lab2
Лабораторная работа №2 по дисциплине "Введение в современную робототехнику на основе ROS"

## 🔌 Требования

| № |                     |
|--------------|---------------------------------|
| 1      | Ubuntu 24.04 |
| 2 | ros2 jalisco(latest)              |
| 3 | python 3.10 или меньше (желательно)                |


## 📦 Запуск проекта 

1. Запуск черепахи

```bash
cd ~/ros2_ws
source install/setup.bash
ros2 run turtlesim turtlesim_node 
```

2. Запуск любой ноды (без атрибутов)

```bash
cd ~/ros2_ws
source install/setup.bash
ros2 run lab_turtlesim NODENAME
```
